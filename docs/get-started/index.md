# Get started with Wanaku Semantic Router

Wanaku Semantic Router (WSR) runs a Barn semantic route as an Apache Camel application and exposes it to Wanaku as one MCP tool. These pages explain how WSR works and help you run a first route.

## Pages in this section

- [How Wanaku Semantic Router works](overview.md): how WSR loads a catalog, registers its tool, and handles calls.
- [Run a route from local files](run-a-local-route.md): start WSR from local route files, without Barn.
